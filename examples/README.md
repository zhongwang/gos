# Runnable example

`example.fasta` retains the existing six sampled test records unchanged.
`example_manifest.json` records their source FASTA basenames, source headers,
and labels, verified by mapping those basenames to `label` in the original
`v4_manifest.tsv` test manifest. Labels are **0 = Natural, 1 = AI**. The existing
selection used seed 42; the manifest lengths now count characters after FASTA
formatting whitespace is removed, matching the CLI (861 and 878 for records
3 and 4).

After installing dependencies as described in
[the quickstart](../README.md), run from the repository root:

```bash
python -m src.gos.cli \
  --input examples/example.fasta \
  --checkpoint models/gos_detector/gos_detector_distilled_genomeocean_100m.pt \
  --output examples/example_output.json \
  --device cpu --dtype float32
```

[`example_output.json`](example_output.json) was generated by actually running
this CLI with the standalone Hugging Face student and shipped production decision
weights. It records the standalone model ID and pinned revision alongside
the runtime versions, derived threshold, labels, calls, confidence scores, and
component logits. The run used Python 3.12.3, PyTorch 2.10.0+cu126, Transformers
4.56.2, and NumPy 2.4.3 on CPU. Values below are rounded for display only.

| Record | true_label | Call | router_confidence |
| --- | ---: | --- | ---: |
| record_1 | 0 | Natural | 3.833126965e-9 |
| record_2 | 0 | Natural | 0.001742071767 |
| record_3 | 1 | AI | 0.999990966462 |
| record_4 | 1 | AI | 0.999999985296 |
| record_5 | 1 | AI | 0.999999994211 |
| record_6 | 1 | AI | 0.999766350226 |

Natural calls have reason `total_logit_below_threshold`; AI calls have reason
`total_logit_at_or_above_threshold`. `router_confidence` always means the AI
score, including for Natural calls. The logit threshold is
`-4.535912535032772`; it was derived from the production reference scores at
FPR 0.05, not from these examples. Six examples do not establish generalization
or a false-positive guarantee. Labels are output annotations only and never
enter the detector computation.
